MOHAMMAD FAYEER PORTFOLIO — UPDATED STARTER SITE

Files:
- index.html — content and sections
- style.css — dark minimal design and responsive layout
- script.js — tab navigation, theme toggle, email form, avatar switching
- avatar-art.png — illustrated avatar
- avatar-photo.jpeg — your supplied profile photo

Preview:
1. Extract this ZIP.
2. Open the folder in VS Code using File > Open Folder.
3. Open index.html with Live Server (or open it directly in a browser).
4. Click the circular avatar to switch between the illustration and your photo.

Publish using GitHub Pages:
1. Create a public repository named Fayirrr.github.io in your GitHub account.
2. Upload index.html, style.css, script.js, avatar-art.png, and avatar-photo.jpeg to the repository root.
3. Open Settings > Pages and choose deploy from the main branch/root.
4. Wait for publication, then test https://fayirrr.github.io/.

Before publishing:
- Verify all descriptions and technologies.
- Confirm the GitHub repository link contains the project before sharing.
- The contact form opens the visitor's email app; it does not store submissions on a server.
